One original English sentence, written as a clause buried deep inside a
terms-of-service agreement — deadpan legal boilerplate until the absurdity
hits:

> All disputes arising under this agreement shall be resolved by a single coin toss performed by a pigeon, and the pigeon's decision shall be final and binding.

The program validates the clause (one sentence, at most 200 characters) and
writes it to `/output/entry.txt` for the house judge. The output is
deterministic: every run writes the same 158-character clause.

Entry for the [make.fun bounty](https://make.fun/bounty/u-donrulezz-the-absurd-clause-contest-035cc0f1).

## Run

```sh
python3 main.py
```
